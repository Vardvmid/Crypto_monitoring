# 💧 Crypto Monitor — Монитор ликвидности топ-5 криптовалют

Простой веб-сайт, который показывает топ-5 криптовалют по рыночной капитализации и оценивает их **ликвидность** на основе отношения объёма торгов за 24 часа к рыночной капитализации.

## 🚀 Что умеет

- Загружает актуальные данные с публичного API **CoinGecko**
- Показывает топ-5 монет по капитализации: Bitcoin, Ethereum, Tether, BNB, Solana
- Отображает цену, изменение за 24 часа, объём торгов и капитализацию
- Рассчитывает **коэффициент ликвидности** (Volume / Market Cap × 100%)
- Присваивает статус:
  - 🟢 **Высокая** — коэффициент ≥ 10%
  - 🟡 **Средняя** — коэффициент от 3% до 10%
  - 🔴 **Низкая** — коэффициент < 3%

## 🛠️ Технологии

- **HTML5** — структура страницы
- **CSS3** — тёмный дизайн и оформление таблицы
- **JavaScript (Vanilla)** — запрос к API и рендеринг таблицы
- **CoinGecko API** — источник данных о криптовалютах

## 📦 Как запустить локально

1. Скачай файл `index.html` из этого репозитория.
2. Открой его в любом современном браузере (Chrome, Firefox, Edge).
3. Готово — сайт сразу загрузит данные и покажет таблицу.

> Никаких установок, серверов или зависимостей не требуется.

## 📊 Как читать таблицу

| Колонка | Что означает |
|---------|--------------|
| Монета | Название и тикер криптовалюты |
| Цена (USD) | Текущая цена в долларах США |
| Изм. 24ч | Изменение цены за последние 24 часа |
| Объём 24ч | Суммарный объём торгов за сутки |
| Кап. | Рыночная капитализация |
| Ликвидность | Коэффициент Volume / Market Cap в процентах |
| Статус | Цветовая оценка ликвидности |

## ⚠️ Ограничения

- CoinGecko в бесплатном режиме может ограничивать частоту запросов. Если данные не загрузились — подожди 30–60 секунд и обнови страницу.
- Данные носят ознакомительный характер и **не являются финансовым советом**.
